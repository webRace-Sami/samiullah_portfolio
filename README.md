## 🛠️ Local Development Quickstart

### 1. Install Dependencies
```bash
npm install
```

### 2. Prisma Database Setup
Generate Prisma client and seed the local database:
```bash
npx prisma generate
npm run prisma:seed
```

### 3. Start Development Server
```bash
# Start Vite Frontend
npm run dev

# Or start fullstack Express + Vite
npm run fullstack
```
Visit `http://localhost:5173` in your browser.

## 🚀 Deployment Guide (Vercel)

### Deploying to Vercel (1-Click Setup)
1. **Push your code to GitHub**:
   ```bash
   git add .
   git commit -m "Update portfolio for Vercel deployment"
   git push origin main
   ```
2. **Go to [Vercel](https://vercel.com/)** and sign in with GitHub.
3. Click **"Add New..."** ➔ **"Project"** and import your `samiullah_portfolio` repository.
4. Vercel automatically detects the Vite framework with pre-configured settings in [vercel.json](file:///Users/mac/Desktop/Projects/samiullah_portfolio/vercel.json):
   - **Framework Preset**: `Vite`
   - **Build Command**: `npm run build`
   - **Output Directory**: `dist`
5. Click **Deploy**. Your live portfolio will be instantly available on your custom Vercel subdomain with global CDN caching and SSL enabled.
